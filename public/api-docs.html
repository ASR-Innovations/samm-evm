GET /quote/:tokenIn/:tokenOut/:amountOut Routing quote — no transaction

Computes the best route and required input amount for an exact-output swap. Uses c-Non-Splitting and Smaller-Better shard selection. No transaction is submitted.

ParamTypeDescription
tokenInrequiredstringToken symbol being sold (USDC, WETH, WBTC, DAI, USDT)
tokenOutrequiredstringToken symbol being bought
amountOutrequirednumberExact amount to receive, in human units (e.g. 0.001 for 0.001 WETH)

Try it

POST /quote Routing quote via JSON body

Same as GET /quote but accepts a JSON body. Useful for programmatic access.

FieldTypeDescription
tokenInrequiredstringToken symbol being sold
tokenOutrequiredstringToken symbol being bought
amountOutrequiredstringExact output amount in human units

Try it


POST /swap Execute on-chain swap via router

Executes an atomic exact-output swap through the on-chain SAMM router. The server's keypair signs. Supports 1-hop and 2-hop routes. All shards selected by the on-chain router program in a single transaction.

FieldTypeDescription
tokenInrequiredstringToken being sold
tokenOutrequiredstringToken being bought
amountOutrequiredstringExact output in human units
slippagePctoptionalstringMax slippage % (default "1.0")

Supported routes: USDC↔USDT, USDC↔DAI, DAI↔USDT, WETH↔USDC, WETH↔USDT, WBTC↔USDC, WBTC→USDT, WBTC→DAI, WETH→DAI, DAI→WETH

Try it — executes a REAL on-chain transaction

POST /faucet Mint test tokens (devnet only)

Mints test tokens to any wallet. Server is the mint authority. Caps: USDC/USDT/DAI ≤ 10,000 · WETH ≤ 5 · WBTC ≤ 0.1 per call.

FieldTypeDescription
addressrequiredstringRecipient wallet public key
tokensrequiredobjectMap of symbol → amount (e.g. {"USDC":100})
